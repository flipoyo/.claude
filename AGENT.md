# AGENT

*Created: 2026-10-27*

This file states the reading order for an agent onboarding to GX4G. It
carries no rules of its own.

1. [`CLAUDE.md`](CLAUDE.md): the map. Load the digest, the two levels, the
   eight steps that finish a change.
2. The fill-in a step points to, in `.agent/.local/.dev/` (the checklist,
   versioning and tickets) or `.agent/.local/.localSpec/` (architecture,
   agent roles, audit findings).
3. The pattern each fill-in names on its `*Fills in:*` line, in
   `.agent/.distant/`.
